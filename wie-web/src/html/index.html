This project is based on wie, created by Inseok Lee.

wie에 오신 것을 환영합니다

wie는 WIPI와 J2ME 앱을 이 기기에서 보관하고 실행할 수 있는 에뮬레이터입니다.

  1. 앱 추가WIPI ZIP 또는 J2ME JAR 파일을 선택합니다.
  2. 앱 실행라이브러리에서 추가된 앱 아이콘을 누릅니다.
  3. 앱 관리오른쪽 위 메뉴에서 앱을 삭제하거나 설정을 변경합니다.

앱 추가

WIPI ZIP 또는 J2ME JAR 파일을 선택하거나 이 창에 끌어다 놓으세요.

앱 삭제


이 앱을 라이브러리에서 삭제합니다.
