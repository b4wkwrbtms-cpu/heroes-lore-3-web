# 영웅서기3 웹앱 (iPhone 홈 화면용)

[dlunch/wie](https://github.com/dlunch/wie) (MIT) 기반 WIPI 에뮬레이터를 GitHub Pages에 배포해
아이폰 홈 화면 웹앱으로 쓰는 프로젝트입니다. 게임 파일은 포함되어 있지 않습니다.

## 사용법
1. Settings → Pages → Source를 **GitHub Actions**로 설정 (최초 1회)
2. Actions 탭에서 빌드가 끝나면 `https://<계정>.github.io/<저장소>/` 로 접속
3. iPhone Safari → 공유 → **홈 화면에 추가** → 홈 화면 아이콘으로 열기
4. 게임 zip(LGT: app_info + .jar 묶음)을 가져오기 → 이후엔 열자마자 자동 실행
   - 라이브러리 화면으로 가려면 `?library` 를 붙여 접속

## 변경점 (upstream 대비)
- `.github/workflows/pages.yml`: Pages 자동 빌드/배포
- `wie-web/public/manifest.webmanifest`, `icon-*.png`, `index.html` 메타: 홈 화면 앱 이름/아이콘
- `wie-web/src/ts/library.ts`: 게임이 1개면 자동 실행

- `wie-web/src/ts/ma3/`, `wie-web/public/ma3_processor.js`: MA-3 SMAF BGM을 원본 FM 음색으로 직접 합성 (GM 사운드폰트 대신)

## 화면 품질과 렌더링
- 설정 → 화질 → **고화질 (화면 크기에 맞춰 선명하게)**: 화면 크기에 따라 EPX 확대를 0~2회 적용하고 마지막에 선명한 보간을 적용합니다.
- 고정 해상도에서는 RGBA 버퍼, JavaScript ImageData, GPU 텍스처를 재사용해 매 프레임의 큰 메모리 할당을 줄입니다.
- GPU 컨텍스트가 사라지면 원본 캔버스로 표시하고, 복구되면 고화질 표시를 다시 시작합니다.
- 원본 스킬·타격 애니메이션, 전투 속도와 판정을 유지합니다. 이 개선은 원본에 없는 애니메이션 프레임을 생성하거나 60 FPS를 보장하지 않습니다.
- 웹앱 업데이트이므로 저장 후 페이지를 새로 열면 적용됩니다. 게임 ZIP을 다시 가져올 필요가 없습니다.

## 명중 효과
- 영웅서기3 LGT판에서 일반 공격·공격 스킬이 실제로 몬스터의 HP를 깎으면 해당 위치에 0.22초 동안 작은 빛과 파편을 더합니다. 버튼 입력, 빗나감, 방어에는 추가 명중 효과를 만들지 않습니다.
- 설정 → **타격 효과**에서 원본 효과만 표시하도록 전환할 수 있습니다. 기기의 동작 줄이기 설정도 따릅니다.
- 추가 효과는 화면 주사율에 맞춰 그리며, 원본 게임의 스킬 프레임이나 공격 판정·속도는 바꾸지 않습니다. 동시 효과는 12개, 렌더링 배율은 2배까지 제한하며 효과가 없을 때는 추가 애니메이션 루프를 중단합니다.
- 카메라 이동·화면 비율·고화질/픽셀 모드에 맞춰 표시합니다. 메뉴, 일시 중지, 숨겨진 탭, 맵 전환에서는 기존 효과를 비웁니다.
- 다른 실행 파일을 잘못 해석하지 않도록 네이티브 코드 서명을 확인합니다. 다른 통신사판/버전에서는 추가 효과를 생략합니다.

## 게임 간 분리
- 영웅서기3는 내부 PID `PD119037`, 이노티아 연대기는 `PD005362`로 구분합니다. 파일 이름이나 표시 이름을 바꿔도 다른 게임의 조작·치트·자동 기능을 선택하지 않습니다. 영웅서기3 메모리 도구는 지원 실행 파일의 네이티브 코드 서명도 확인합니다.
- 돈·드랍·장신구 치명타 +20%·스탯 10/스킬 3·경험치 2배·버프·강화 변경은 영웅서기3 게임 ZIP에만 들어 있습니다. 웹 실행기는 이 규칙을 다른 게임에 주입하지 않습니다.
- 게임 파일, 파일 저장 및 레코드 저장, 저장한 치트와 자동 설정은 PID별로 유지합니다. 화질·화면 비율·음악 엔진·추가 타격 효과 설정도 게임별로 저장합니다. 이전 공통 화질/비율/음악 선택은 영웅서기3에만 한 번 이어받습니다.
- 게임 종료 시 자동 물약·스킬·매크로 대기열·회복 타이머·키 표시·타격 효과를 정리합니다. 이노티아에는 영웅서기3 매크로 버튼과 추가 타격 효과가 표시되지 않습니다.
- 기존 세이브 저장소나 게임 파일은 삭제하거나 이름을 바꾸지 않습니다. 게임별 설정을 분리하는 데 재설치가 필요하지 않습니다. 언어와 전체 음량은 실행기 공통 설정입니다.

렌더러·명중 효과·게임 분리 회귀 검사: `node --test wie-web/tests/*.test.cjs`
