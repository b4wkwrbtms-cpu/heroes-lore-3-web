# 영웅서기3 웹앱 (iPhone 홈 화면용)

[dlunch/wie](https://github.com/dlunch/wie) (MIT) 기반 WIPI 에뮬레이터를 GitHub Pages에 배포해
아이폰 홈 화면 웹앱으로 쓰는 프로젝트입니다. 게임 파일은 포함되어 있지 않습니다.

## 사용법
1. Settings → Pages → Source를 **GitHub Actions**로 설정 (최초 1회)
2. Actions 탭에서 빌드가 끝나면 `https://<계정>.github.io/<저장소>/` 로 접속
3. iPhone Safari → 공유 → **홈 화면에 추가** → 홈 화면 아이콘으로 열기
4. 게임 zip(LGT: app_info + .jar 묶음)을 가져오기 → 이후엔 열자마자 자동 실행
   - 라이브러리 화면으로 가려면 `?library` 를 붙여 접속

## 변경점 (upstream 대비)
- `.github/workflows/pages.yml`: Pages 자동 빌드/배포
- `wie-web/public/manifest.webmanifest`, `icon-*.png`, `index.html` 메타: 홈 화면 앱 이름/아이콘
- `wie-web/src/ts/library.ts`: 게임이 1개면 자동 실행

- `wie-web/src/ts/ma3/`, `wie-web/public/ma3_processor.js`: MA-3 SMAF BGM을 원본 FM 음색으로 직접 합성 (GM 사운드폰트 대신)

## 화면 품질과 렌더링
- 설정 → 화질 → **고화질 (화면 크기에 맞춰 선명하게)**: 화면 크기에 따라 EPX 확대를 0~2회 적용하고 마지막에 선명한 보간을 적용합니다.
- 고정 해상도에서는 RGBA 버퍼, JavaScript ImageData, GPU 텍스처를 재사용해 매 프레임의 큰 메모리 할당을 줄입니다.
- GPU 컨텍스트가 사라지면 원본 캔버스로 표시하고, 복구되면 고화질 표시를 다시 시작합니다.
- 원본 스킬·타격 애니메이션, 전투 속도와 판정을 유지합니다. 이 개선은 원본에 없는 애니메이션 프레임을 생성하거나 60 FPS를 보장하지 않습니다.
- 웹앱 업데이트이므로 저장 후 페이지를 새로 열면 적용됩니다. 게임 ZIP을 다시 가져올 필요가 없습니다.

## 명중 효과
- 영웅서기3 LGT판에서 일반 공격·공격 스킬이 실제로 몬스터의 HP를 깎으면 해당 위치에 0.22초 동안 작은 빛과 파편을 더합니다. 버튼 입력, 빗나감, 방어에는 추가 명중 효과를 만들지 않습니다.
- 설정 → **타격 효과**에서 원본 효과만 표시하도록 전환할 수 있습니다. 기기의 동작 줄이기 설정도 따릅니다.
- 추가 효과는 화면 주사율에 맞춰 그리며, 원본 게임의 스킬 프레임이나 공격 판정·속도는 바꾸지 않습니다. 동시 효과는 12개, 렌더링 배율은 2배까지 제한하며 효과가 없을 때는 추가 애니메이션 루프를 중단합니다.
- 카메라 이동·화면 비율·고화질/픽셀 모드에 맞춰 표시합니다. 메뉴, 일시 중지, 숨겨진 탭, 맵 전환에서는 기존 효과를 비웁니다.
- 다른 실행 파일을 잘못 해석하지 않도록 네이티브 코드 서명을 확인합니다. 다른 통신사판/버전에서는 추가 효과를 생략합니다.

## 영웅서기 제로 (KTF)
- 게임 ZIP(`__adf__` + `010100D5.jar` + `P/` 데이터 폴더)을 그대로 가져오면 됩니다. 영웅서기3·이노티아와 같은 앱에서 PID `PD005576`으로 따로 관리됩니다.
- 조이스틱은 8방향입니다. 이 게임은 방향키 두 개를 함께 누르면 대각선으로 걷기 때문에, 대각선 구역에서는 두 키를 같이 누릅니다. 곧게 걸을 때 손가락이 조금 흔들려도 대각선이 되지 않도록 직선 구역(52°)을 대각선 구역(38°)보다 넓게 잡고, 경계에서는 8° 여유를 둡니다.
- 메뉴·상점·대화 선택지에서는 조이스틱이 방향키 패드처럼 한 방향만 보내고, 누르고 있으면 0.38초 뒤부터 계속 넘어갑니다(게임은 누를 때마다 한 칸만 움직입니다). 화면 종류는 게임 메모리의 상태 값으로 구분하며, 지원하는 실행 파일(v1.0.2)일 때만 사용합니다.
- 메뉴에서는 숫자키가 항목 바로가기(2 = 인벤토리 등)라서 조이스틱은 항상 방향키를 보냅니다. 공격·확인·대화 = OK, 스킬 = 1·3·7·9, 회복 아이템 = 0·#(#은 장면 스킵), 미니맵 = *, 메뉴 = CLR.
- 위쪽 **저장** 버튼: 게임 도움말의 퀵세이브 키(우측상단키)는 에뮬레이터의 어떤 키로도 동작하지 않아, 게임 메뉴(CLR → 7 시스템 → 세이브 → 예)를 대신 눌러 저장합니다. 필드에서만 시작하고, 매 단계 화면을 확인해 예상과 다르면 멈춥니다.
- **히든 직업으로 시작**: 새로하기의 전투스타일 선택 화면에서 원래 4개(워리어·로그·나이트·건슬링어)에 더해 숨겨진 직업 **검총사·정령사**도 좌우로 넘겨 고를 수 있습니다. 게임이 이미 가진 6개 직업 데이터를 그대로 쓰며, 이 화면의 선택 개수(4→6)와 두 직업의 공개 표시만 바꿉니다. 고른 뒤에는 게임이 평소처럼 그 직업으로 주인공을 만듭니다(검총사는 시작 무기 총검 포함).
- **정령사는 처음부터 정령 사용**: 원래 메뉴의 5번 정령(SPIRIT)은 4번째 메인 퀘스트 "정령"에서 카르멘이 합류하기 전까지 "아직 사용할 수 없습니다"로 막혀 있습니다. 주인공이 정령사이면 메뉴가 열려 있는 동안 이 잠금만 풀어, 처음부터 정령 창에서 스킬 포인트를 투자하고 7·9번에 등록해 필드에서 쓸 수 있습니다(마력은 원래처럼 공격하거나 맞으면 찹니다). 퀘스트 진행·저장 데이터는 건드리지 않으므로 이야기는 원래대로 흘러가고, 다른 직업은 원래대로 퀘스트 후에 열립니다.
- **타격 효과**: 몬스터의 HP가 실제로 줄어든 순간 그 몬스터 위에 짧은 빛·고리·파편을 더합니다. 큰 피해(최대 HP의 25% 이상)는 더 크게, 쓰러뜨린 일격은 이중 고리로 보이고, 주인공이 맞으면 화면 가장자리가 잠깐 붉어집니다. 게임의 맵·몬스터·카메라 정보를 읽기만 하며(v1.0.2 실행 파일일 때만), 원본 베기 연출·데미지 숫자·공격 속도와 판정은 그대로입니다. 설정 → 타격 효과에서 끌 수 있고, 기기의 동작 줄이기 설정도 따릅니다.

## 영웅서기4 - 환영의 가면 (LGT)
- 안드로이드판 APK 안의 게임 ZIP(`app_info` + `0002D74B.jar` + `P/`)을 그대로 가져오면 됩니다. PID `PD140249`로 따로 관리됩니다.
- 전용 액션 패드: 왼쪽은 떠다니는 조이스틱(4방향 — 이 게임은 방향키 두 개를 같이 눌러도 대각선으로 걷지 않습니다), 오른쪽은 공격(OK) 둘레에 회피·단축키 1·3·7·9·0·벨트 교체(#), 위쪽은 미니맵(*)·퀵세이브(통화키)·메뉴(CLR)·⋯ 입니다.
- **회피**: 게임의 특수이동(같은 방향키를 빠르게 두 번 = 휴먼 구르기·네베드 순간이동)을 마지막으로 걸은 방향으로 한 번에 냅니다. 방향키를 잡고 있었다면 두 번 누른 뒤 다시 잡은 상태로 돌려 놓습니다.
- 게임 키: 이동 = 방향키, 조사·대화·공격 = OK, 단축키 = 1·3·7·9·0, 단축벨트 교체·장면 스킵 = #, 미니맵 = *, 메뉴 = CLR, 퀵세이브 = 통화키. 나머지 키(2·4·5·6·8, 소프트키)는 ⋯ → 전체 키패드에 있습니다.
- **타격감**: 몬스터의 HP가 실제로 줄어든 순간 그 몬스터 몸 위에 불꽃(튀는 파편)·빛·베기 섬광을 더하고, 게임을 아주 잠깐 멈추고(히트스톱 0.024초, 큰 피해 0.05초, 처치 0.06초) 화면을 살짝 흔듭니다. 큰 피해(최근 평균보다 35% 이상 센 일격 — 치명타·강한 스킬 — 또는 최대 HP의 절반 이상)는 화면이 따뜻하게 번쩍이고, 쓰러뜨린 일격은 고리 두 개와 파편이 퍼집니다. 주인공이 맞으면 화면 가장자리가 붉어지고 살짝 흔들립니다. 게임의 필드 목록(주인공·몬스터·사물이 그리는 순서대로 이어진 목록)과 카메라를 읽기만 하며(v1.0.1 실행 파일일 때만), 원본 베기 연출·데미지 숫자·공격 판정은 그대로입니다. 설정 → 타격 효과에서 모두 끌 수 있고, 기기의 동작 줄이기 설정을 켜면 흔들림과 멈춤은 빠집니다.
- 화질: 다른 게임과 같은 고화질(화면 크기에 맞춘 EPX 확대 + 선명한 보간)이 기본이며, 설정에서 픽셀 그대로로 바꿀 수 있습니다(게임별 저장). 영웅서기4는 차분한 원본 색에 채도(+16%)와 대비(+7%)를 조금 더해 보여 줍니다.
- 프레임: 게임 자체가 초당 약 20장을 그리는 피처폰 게임이라, 원본에 없는 중간 장면을 지어내지는 않습니다(그림이 번지거나 조작이 늦어지기 때문). 대신 효과는 화면 주사율(아이폰 14 Pro는 최대 120Hz)로 부드럽게 그립니다.

## 게임 간 분리
- 영웅서기3는 내부 PID `PD119037`, 이노티아 연대기는 `PD005362`, 영웅서기 제로는 `PD005576`, 영웅서기4는 `PD140249`로 구분합니다. 파일 이름이나 표시 이름을 바꿔도 다른 게임의 조작·치트·자동 기능을 선택하지 않습니다. 영웅서기3 메모리 도구는 지원 실행 파일의 네이티브 코드 서명도 확인합니다.
- 돈·드랍·장신구 치명타 +20%·스탯 10/스킬 3·경험치 2배·버프·강화 변경은 영웅서기3 게임 ZIP에만 들어 있습니다. 웹 실행기는 이 규칙을 다른 게임에 주입하지 않습니다.
- 게임 파일, 파일 저장 및 레코드 저장, 저장한 치트와 자동 설정은 PID별로 유지합니다. 화질·화면 비율·음악 엔진·추가 타격 효과 설정도 게임별로 저장합니다. 이전 공통 화질/비율/음악 선택은 영웅서기3에만 한 번 이어받습니다.
- 게임 종료 시 자동 물약·스킬·매크로 대기열·회복 타이머·키 표시·타격 효과를 정리합니다. 이노티아에는 영웅서기3 매크로 버튼과 추가 타격 효과가 표시되지 않습니다. 영웅서기 제로에는 매크로 버튼이 없고, 타격 효과는 제로의 메모리 구조로 따로 동작합니다(영웅서기3 효과 코드와 공유하지 않음). 영웅서기4의 타격감은 따로 만든 코드로, 제로·영웅서기3 효과 코드와 공유하지 않습니다. 영웅서기3·이노티아의 조이스틱(4방향, 한 번에 한 키)과 버튼 배치는 제로 추가 전과 같습니다.
- 기존 세이브 저장소나 게임 파일은 삭제하거나 이름을 바꾸지 않습니다. 게임별 설정을 분리하는 데 재설치가 필요하지 않습니다. 언어와 전체 음량은 실행기 공통 설정입니다.
