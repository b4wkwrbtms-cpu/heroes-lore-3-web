# 영웅서기3 웹앱 (iPhone 홈 화면용)

[dlunch/wie](https://github.com/dlunch/wie) (MIT) 기반 WIPI 에뮬레이터를 GitHub Pages에 배포해
아이폰 홈 화면 웹앱으로 쓰는 프로젝트입니다. 게임 파일은 포함되어 있지 않습니다.

## 사용법
1. Settings → Pages → Source를 **GitHub Actions**로 설정 (최초 1회)
2. Actions 탭에서 빌드가 끝나면 `https://<계정>.github.io/<저장소>/` 로 접속
3. iPhone Safari → 공유 → **홈 화면에 추가** → 홈 화면 아이콘으로 열기
4. 게임 zip(LGT: app_info + .jar 묶음)을 가져오기 → 이후엔 열자마자 자동 실행
   - 라이브러리 화면으로 가려면 `?library` 를 붙여 접속

## 변경점 (upstream 대비)
- `.github/workflows/pages.yml`: Pages 자동 빌드/배포
- `wie-web/public/manifest.webmanifest`, `icon-*.png`, `index.html` 메타: 홈 화면 앱 이름/아이콘
- `wie-web/src/ts/library.ts`: 게임이 1개면 자동 실행

- `wie-web/src/ts/ma3/`, `wie-web/public/ma3_processor.js`: MA-3 SMAF BGM을 원본 FM 음색으로 직접 합성 (GM 사운드폰트 대신)

## 끊김(렉) 줄이기
- 게임이 명령어 캐시 전체 무효화(CP15 c7)를 실행해도, 미리 번역해 둔 ARM 코드 중 **명령어가 실제로 바뀐 영역만** 버리고 다시 번역합니다. 전에는 모든 영역을 버려서, 게임이 데이터를 읽을 때마다 캐시를 비우는 영웅서기4는 플레이 내내 코드가 한 조각씩 다시 번역되며(같은 플레이 구간에서 2,070번 → 26번) 끊겼습니다. 번역 결과는 명령어 바이트로만 정해지므로 바뀌지 않은 영역은 그대로 쓸 수 있습니다.

## 화면 품질과 렌더링
- 설정 → 화질 → **고화질 (화면 크기에 맞춰 선명하게)**: 화면 크기에 따라 EPX 확대를 0~2회 적용하고 마지막에 선명한 보간을 적용합니다.
- 영웅서기3·제로·4의 고화질은 영웅서기5 플레이어와 같은 방식입니다: 가장자리 방향을 판정하는 2단계 업스케일러(대각선과 2:1 기울기 타일이 계단 없이 이어짐)를 화면 크기에 맞춰 바로 그리고, 불·마법·불꽃처럼 밝고 색이 있는 곳에 은은한 빛 번짐을 더하며(흰 패널·글자는 제외), 채도 +16%·대비 +7%로 색을 조금 살립니다. 영웅서기3는 빛 번짐을 더 넓게(0.85), 색 보정은 약하게(채도 +10%·대비 +4%) 해 스킬 빛이 튀지 않고 부드럽게 섞입니다(추가 연산 없음). 세 게임의 추가 타격 효과(고리·불꽃·별 섬광)도 영웅서기5처럼 게임 픽셀 격자에 맞춘 네모 점으로 그립니다. 다른 게임은 기존 EPX 방식 그대로입니다.
- 고정 해상도에서는 RGBA 버퍼, JavaScript ImageData, GPU 텍스처를 재사용해 매 프레임의 큰 메모리 할당을 줄입니다.
- GPU 컨텍스트가 사라지면 원본 캔버스로 표시하고, 복구되면 고화질 표시를 다시 시작합니다.
- 원본 스킬·타격 애니메이션, 전투 속도와 판정을 유지합니다. 화질 설정 자체는 원본에 없는 프레임을 만들지 않습니다(움직임은 아래 "중간 프레임" 참고).
- 웹앱 업데이트이므로 저장 후 페이지를 새로 열면 적용됩니다. 게임 ZIP을 다시 가져올 필요가 없습니다.

## 중간 프레임 (부드러운 움직임)
- 영웅서기3 LGT판은 필드에서 초당 30번쯤 그리며 한 번에 8픽셀씩 움직입니다. 설정 → **움직임 → 부드럽게**(기본)에서는 게임 프레임 사이마다, 카메라·주인공·NPC·몬스터를 직전 위치와 현재 위치의 중간에 놓고 게임 자신의 그리기 루틴으로 화면을 한 번 더 그립니다. 영웅서기5 플레이어의 중간 프레임과 같은 방식이며, 걷기·카메라 이동이 화면 주사율(60Hz)에 맞춰 4픽셀씩 이어집니다.
- 그림을 섞거나 늘리는 보간이 아니라 게임이 실제 타일·스프라이트로 다시 그린 화면입니다. 그린 뒤에는 게임 메모리(위치, 깜빡임 카운터, 스프라이트의 화면 안/밖 표시)를 원래대로 되돌리므로 게임 진행·전투 판정·속도는 그대로입니다. 스프라이트의 애니메이션 프레임은 원본 그대로이고 위치만 나눠 움직입니다.
- 주인공의 공격·스킬 자세도 같은 방식으로 이어집니다. 게임은 주인공 한 자세를 머리·몸통·다리·손·무기·칼빛 조각의 목록(조각마다 위치, 무기·칼빛은 크기·회전·투명도까지)으로 조립해 그립니다. 앞뒤 자세에 같은 조각이 있으면 그 조각의 위치를 둘 사이 값으로 놓고 게임이 직접 다시 그리므로, 원본 도트 그대로 중간 자세가 생깁니다. 앞 자세에 없던 조각(다른 그림으로 바뀐 팔다리, 새로 나타난 칼빛)은 원본처럼 바로 나타납니다. 그림을 섞지 않아 흐려지지 않습니다. 크기·회전·투명도는 원본 값 그대로 둡니다(게임은 무기를 정해진 단계로만 제대로 그려서, 사이 값을 주면 무기가 희미해지거나 깨지거나 사라졌습니다).
- 항상 다음 실제 위치를 알고 움직이도록 화면은 게임 프레임 하나(약 1/30초)만큼 늦게 따라갑니다. 아무것도 움직이지 않을 때는 원본 프레임을 바로 보여 줍니다.
- 대화·메뉴·컷신 등 필드가 아닌 화면, 맵 이동이나 48픽셀이 넘는 순간 이동은 원본 프레임만 보여 줍니다. 한 번 그리는 데 시간이 너무 걸리는 기기에서는 자동으로 원본 프레임만 보여 줍니다. **원본 프레임만**을 고르면 끕니다(게임별 저장).
- 에뮬레이터에는 게임 태스크가 모두 쉬는 사이에 게임 함수를 호출하는 범용 통로(`guest_idle`, `guest_call`)만 더했고, 게임별 주소와 그리기 순서는 웹 쪽 데이터(`hl3_motion.ts`)에 있습니다. 지원 실행 파일 서명이 다르면 동작하지 않습니다.

## 연계(콤보) 입력 보정
- 영웅서기3의 주무기 연계는 게임 프레임 단위로 받습니다. 앞 공격을 누른 뒤 약 3프레임 안에 다시 눌러야 다음 타로 이어지고, 그 뒤 4프레임 동안 누른 입력은 버려지며, 그 후에 누르면 새 1타가 됩니다. 이 에뮬레이터에서 게임 속도 8~10은 한 프레임이 10~30ms라서 이 구간이 사람의 두 번째 입력보다 훨씬 짧아, 단검처럼 빠른 무기는 1타만 나가고 연계가 끊겼습니다.
- 이제 연계를 받는 구간을 프레임이 아닌 실제 시간(각 타가 시작된 뒤 0.3초, 게임 속도 6 정도의 감각)으로 유지합니다. 그 안에 공격(확인·5)을 누르면 게임 속도와 상관없이 다음 타로 이어집니다. 게임이 원래 허용하는 연계 횟수(첫 액티브 스킬 레벨)는 그대로이고, 게임 메모리의 연계 단계 값은 건드리지 않고 대기 카운터만 조정합니다.
- 보정으로 늘어난 대기 시간 동안 스킬·아이템 단축키(1·3·9·0·#)를 누르면 대기를 끝내고 바로 사용되게 해, 원래보다 스킬이 막히지 않습니다. 보조무기 연계(7)는 원래부터 이 대기 구간이 없어 그대로입니다.
- 필드에서만 작동하며 다른 게임에는 적용되지 않습니다.

## 영웅서기3 조작 패드와 퀘스트 안내
- 세로 화면에서 영웅서기3의 단축키(1·3·9·0·#)·보조(7)는 지름 72, 공격은 96 단위로 키우고(기존 52~56·92), 조이스틱도 더 크게 놓았습니다. 패드 높이를 조금 늘려 자리를 만들었고, 키와 동작은 그대로입니다. 다른 게임의 패드는 바뀌지 않습니다.
- 퀘스트 안내 칸은 접기 버튼과 펼친 설명만 터치를 받고, 나머지 부분은 터치가 아래 조이스틱 영역으로 그대로 지나갑니다.
- 퀘스트 안내 지점: 퀘스트를 실제로 완료시키는 지점(완료 이벤트, 또는 완료 컷신을 시작하는 지점)을 먼저 찾아 가리킵니다. 문만 지나는 길로 닿지 않으면 대화·컷신을 거치는 길까지 찾아보고, 그래도 없을 때만 퀘스트 설명의 지역 이름으로 안내합니다. 이전에는 컷신에서 완료되는 퀘스트(예: "수상한 동굴")가 설명의 지역 이름(네메시스숲)을 따라 동굴 밖 출구를 가리켰습니다. 사냥 퀘스트는 그 지역의 맵에 대상 몬스터가 없으면 같은 지역의 다음 가까운 맵으로 안내합니다.

## 소울마스터 마법진
- 영웅서기3 소울마스터가 공격할 때 발밑 마법진과 함께 위로 떠오르는 마법진 복사본이 나옵니다. 원래는 이 복사본을 불투명도 180·120·90(255 기준)으로 그려 배경에 묻혀 흐릿했습니다. 지금 보이는 프레임의 애니메이션 기록에서 이 세 값만 255·230·200으로 올려, 위쪽 마법진도 발밑 것과 비슷하게 또렷이 보이고 올라갈수록 옅어지는 느낌은 남깁니다. 무기 종류가 소울마스터일 때만, 무기 레이어의 해당 조각 불투명도만 바꿉니다(각 프레임은 처음 한 번 나온 뒤부터 적용).

## 명중 효과
- 영웅서기3 LGT판에서 일반 공격·공격 스킬이 실제로 몬스터의 HP를 깎으면 해당 위치에 0.36초 동안 작은 빛과 파편을 더하고, 화면(게임·업스케일 화면·효과 전체)을 1~2픽셀 0.11초 흔들었다 제자리로 돌립니다. 흔들림은 화면 위치만 옮기므로 다시 그리는 비용이 없고, 게임을 멈추는 히트스톱은 없습니다. 버튼 입력, 빗나감, 방어에는 추가 명중 효과를 만들지 않습니다.
- 설정 → **타격 효과**에서 원본 효과만 표시하도록 전환할 수 있습니다. 기기의 동작 줄이기 설정도 따릅니다.
- **데미지 숫자**: 원래는 맞은 순간부터 5게임 프레임(속도 6에서 0.2초 미만, 빠른 속도에서는 더 짧게)만 떠 있었습니다. 이제 숫자가 떠오르는 단계마다 실제 시간 0.08초씩 보여 약 0.3초 동안 머물고, 마지막 사라지는 단계만 게임 속도대로 진행합니다. 몬스터 위 숫자에만 해당하고(주인공이 맞은 피해·miss 숫자는 원래 속도대로), 게임 메모리의 숫자 나이 값만 늦출 뿐 피해량·판정은 그대로입니다. 필드에서만 동작합니다.
- 추가 효과는 화면 주사율에 맞춰 그리며, 원본 게임의 스킬 프레임이나 공격 판정·속도는 바꾸지 않습니다. 동시 효과는 12개, 렌더링 배율은 2배까지 제한하며 효과가 없을 때는 추가 애니메이션 루프를 중단합니다.
- 카메라 이동·화면 비율·고화질/픽셀 모드에 맞춰 표시합니다. 메뉴, 일시 중지, 숨겨진 탭, 맵 전환에서는 기존 효과를 비웁니다.
- 다른 실행 파일을 잘못 해석하지 않도록 네이티브 코드 서명을 확인합니다. 다른 통신사판/버전에서는 추가 효과를 생략합니다.

## 영웅서기 제로 (KTF)
- 게임 ZIP(`__adf__` + `010100D5.jar` + `P/` 데이터 폴더)을 그대로 가져오면 됩니다. 영웅서기3·이노티아와 같은 앱에서 PID `PD005576`으로 따로 관리됩니다.
- 조이스틱은 8방향입니다. 이 게임은 방향키 두 개를 함께 누르면 대각선으로 걷기 때문에, 대각선 구역에서는 두 키를 같이 누릅니다. 곧게 걸을 때 손가락이 조금 흔들려도 대각선이 되지 않도록 직선 구역(52°)을 대각선 구역(38°)보다 넓게 잡고, 경계에서는 8° 여유를 둡니다.
- 메뉴·상점·대화 선택지에서는 조이스틱이 방향키 패드처럼 한 방향만 보내고, 누르고 있으면 0.38초 뒤부터 계속 넘어갑니다(게임은 누를 때마다 한 칸만 움직입니다). 화면 종류는 게임 메모리의 상태 값으로 구분하며, 지원하는 실행 파일(v1.0.2)일 때만 사용합니다.
- 메뉴에서는 숫자키가 항목 바로가기(2 = 인벤토리 등)라서 조이스틱은 항상 방향키를 보냅니다. 공격·확인·대화 = OK, 스킬 = 1·3·7·9, 회복 아이템 = 0·#(#은 장면 스킵), 미니맵 = *, 메뉴 = CLR.
- 위쪽 **저장** 버튼: 게임 도움말의 퀵세이브 키(우측상단키)는 에뮬레이터의 어떤 키로도 동작하지 않아, 게임 메뉴(CLR → 7 시스템 → 세이브 → 예)를 대신 눌러 저장합니다. 필드에서만 시작하고, 매 단계 화면을 확인해 예상과 다르면 멈춥니다.
- **히든 직업으로 시작**: 새로하기의 전투스타일 선택 화면에서 원래 4개(워리어·로그·나이트·건슬링어)에 더해 숨겨진 직업 **검총사·정령사**도 좌우로 넘겨 고를 수 있습니다. 게임이 이미 가진 6개 직업 데이터를 그대로 쓰며, 이 화면의 선택 개수(4→6)와 두 직업의 공개 표시만 바꿉니다. 고른 뒤에는 게임이 평소처럼 그 직업으로 주인공을 만듭니다(검총사는 시작 무기 총검 포함).

- 주소: `/z4/`. 제노니아4 안드로이드판 APK(또는 APK가 든 ZIP)와 가속 파일(`z4fast.wasm`)을 함께 골라 한 번 넣으면 기기에 저장되고, 이후에는 바로 시작합니다. 홈 화면에 추가하면 전체 화면 가로 모드로 열립니다. 세로로 들면 화면을 돌려서 보여 줍니다.
- 원본 실행 파일(`libgameDSO.so`, ARMv7 Thumb-2·VFP)을 새로 만든 실행기로 그대로 돌립니다(`wie-web/z4-core`). 게임이 화면 너비에 맞춰 HUD를 가장자리에 붙이고 필드를 넓게 보여 주므로, 높이 480에 아이폰 비율만큼 넓혀(아이폰 14 Pro에서 약 1040) 늘이지 않고 꽉 채웁니다. 카메라 쪽만 비우기(기본)·양쪽 비우기·끝까지 채우기를 고를 수 있습니다.
- 조작은 게임 화면에 원래 있는 터치 패드(방향 다이얼)·공격·스킬·메뉴 버튼을 그대로 씁니다. 손가락마다 따로 포인터 번호를 주므로 방향을 누른 채 공격·스킬을 누를 수 있고, 안드로이드처럼 한 프레임에 손가락마다 누름·뗌을 하나씩 전달해 짧게 톡 친 것도 놓치지 않습니다. 게임 옵션의 D.PAD OPACITY로 패드 투명도를 바꿀 수 있습니다.
- 글자는 원래 자바(NexusFont)가 그리던 것을 페이지가 캔버스로 그려 줍니다(줄바꿈 계산 포함). 기기 언어를 한국어로 알려 주므로 처음부터 한국어로 나오며, 게임 옵션 → LANGUAGE에서 바꿀 수 있습니다.
- 게임 속도는 게임이 정한 초당 프레임(옵션의 GAME SPEED)을 따릅니다. 서명 검사는 원본 값으로 통과시키고, 결제·게임빌 라이브·네트워크 기능은 쓸 수 없습니다.
- **가속 파일**: 그림을 그리는 함수 등 바쁜 함수 583개를 미리 C로 번역해 넣은 코어로, 해석 실행보다 약 8배 빠릅니다(아이폰에서 제 속도를 내려면 필요). 게임 코드로 만든 것이라 저장소에는 넣지 않으며, 같은 실행 파일(코드 체크섬 확인)에서만 켜지고 다르면 해석 실행으로 돌아갑니다. 설정 → 가속 파일에서 넣거나 바꿀 수 있습니다. 만드는 방법은 `wie-web/z4-core/README.md`.
- 세이브는 IndexedDB(`zenonia4-player`)에 따로 저장되며 설정에서 백업·복원할 수 있습니다. 다른 게임의 저장소·설정(`z4.prefs`)과 섞이지 않습니다.

## 게임 간 분리
- 영웅서기3는 내부 PID `PD119037`, 이노티아 연대기는 `PD005362`, 영웅서기 제로는 `PD005576`, 영웅서기4는 `PD140249`로 구분합니다. 파일 이름이나 표시 이름을 바꿔도 다른 게임의 조작·치트·자동 기능을 선택하지 않습니다. 영웅서기3 메모리 도구는 지원 실행 파일의 네이티브 코드 서명도 확인합니다.
- 돈·드랍·장신구 치명타 +20%·스탯 10/스킬 3·경험치 2배·버프·강화 변경은 영웅서기3 게임 ZIP에만 들어 있습니다. 웹 실행기는 이 규칙을 다른 게임에 주입하지 않습니다.
- 게임 파일, 파일 저장 및 레코드 저장, 저장한 치트와 자동 설정은 PID별로 유지합니다. 화질·화면 비율·음악 엔진·추가 타격 효과 설정도 게임별로 저장합니다. 이전 공통 화질/비율/음악 선택은 영웅서기3에만 한 번 이어받습니다.
- 게임 종료 시 자동 물약·스킬·매크로 대기열·회복 타이머·키 표시·타격 효과를 정리합니다. 이노티아에는 영웅서기3 매크로 버튼과 추가 타격 효과가 표시되지 않습니다. 영웅서기 제로에는 매크로 버튼이 없고, 타격 효과는 제로의 메모리 구조로 따로 동작합니다(영웅서기3 효과 코드와 공유하지 않음). 영웅서기4의 타격감은 따로 만든 코드로, 제로·영웅서기3 효과 코드와 공유하지 않습니다. 영웅서기3·이노티아의 조이스틱(4방향, 한 번에 한 키)과 버튼 배치는 제로 추가 전과 같습니다.
- 기존 세이브 저장소나 게임 파일은 삭제하거나 이름을 바꾸지 않습니다. 게임별 설정을 분리하는 데 재설치가 필요하지 않습니다. 언어와 전체 음량은 실행기 공통 설정입니다.

### 영웅서기 3 전달용 v8

영웅서기 3(PID `PD119037`)은 원작 드랍·경험치·스탯·스킬·마나 소비·쿨타임 규칙으로 복구합니다. 예외는 소지금 99,999,999 자동 유지, 제련석 없이 강화, 모든 강화 단계의 성공률 80%입니다. 원작의 강화 가능 부위, +10 상한, 실패 시 결과는 유지합니다. 그래픽·조작·퀘스트 안내와 로딩 최적화도 유지합니다.

사용자의 전달용 초기화 요청에 따라 **v8 첫 실행 직전에 영웅서기 3의 기존 저장 기록을 한 번 삭제**합니다. 이후의 새 저장은 재실행해도 유지됩니다. 이노티아·영웅서기 4 등 다른 PID의 기록과 설정은 변경하지 않습니다. 예전 영웅서기 3 치트·매크로 설정은 제거하며, 이 게임의 치트 메뉴와 자동 재적용 경로도 제거했습니다.

원본·v5·v6·v7 게임 파일은 SHA-256을 확인한 뒤 해당 앱의 보관 파일만 자동 갱신합니다. 알 수 없는 파일은 수정하거나 실행하지 않고 전달용 v8 ZIP을 다시 추가하도록 안내합니다. 입력 ZIP과 게임 저장은 별도 보관되며, 게임 파일에 개인 저장 데이터는 포함하지 않습니다.

The MA-3 FM synthesizer follows the YMF825 (SD-1) tone parameter documentation published by Yamaha
for the YMF825Board, and the SMAF voice exclusive layouts documented by [go-smaf](https://github.com/but80/go-smaf) (MIT).
